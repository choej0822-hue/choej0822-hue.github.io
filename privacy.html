혼자놀자 개인정보처리방침

시행일: 2026년 10월 1일

혼자놀자(이하 ‘앱’)는 서울 혼놀 코스를 추천하는 서비스예요. 앱은 이용자의 개인정보를 받지 않도록 만들었어요. 자세한 내용은 아래와 같아요.

1. 수집하는 개인정보

회원가입이 없고, 이름·연락처·이메일 같은 개인정보를 받지 않아요.

2. 기기에만 저장되는 정보

코스 조건 설정과 찜한 장소는 이용자의 기기(브라우저 저장소)에만 저장돼요. 운영자에게 전송되지 않고, 앱 데이터나 브라우저 데이터를 지우면 함께 지워져요.

3. 위치 정보

‘내 위치에서 출발’을 고른 경우에만 기기의 현재 위치를 한 번 확인해서 코스 계산에 써요. 위치는 기기 안에서만 쓰이고, 저장하거나 외부로 보내지 않아요. 위치 권한은 언제든 기기 설정에서 끌 수 있어요.

4. 혼놀 정보 제보

장소 화면의 ‘제보하기’로 제보를 보내면 장소 이름, 고른 항목, 체감 난이도, 다녀온 때, 한 줄 팁이 Google 설문지(Google LLC)를 거쳐 운영자에게 전달돼요. 이름·연락처·위치는 받지 않아요. 제보는 장소 정보를 확인하고 고치는 데만 쓰고, 앱에 그대로 공개하지 않아요. 반영이 끝난 제보는 1년 안에 지워요. 한 줄 팁에는 개인정보를 적지 말아 주세요.

5. 광고·분석 도구

광고와 사용 분석 도구(트래커)를 쓰지 않아요.

6. 외부 서비스로 이동

‘네이버 지도’, ‘카카오맵’ 버튼을 누르면 해당 서비스로 이동해요. 이동한 뒤에는 각 서비스의 개인정보처리방침이 적용돼요.

7. 웹사이트 호스팅

앱 화면은 GitHub Pages(GitHub, Inc.)를 통해 제공돼요. 호스팅 업체는 보안과 서비스 운영을 위해 접속한 기기의 IP 주소 같은 접속 기록을 처리할 수 있어요.

8. 아동의 개인정보

앱은 개인정보를 받지 않으므로, 만 14세 미만 아동의 개인정보도 수집하지 않아요.
